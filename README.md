# Говор

Диктовка голосом в любое окно Windows. Удерживайте клавишу и говорите; отпустите —
текст появится там, где стоит курсор: в письме, чате, документе, редакторе кода.

Распознавание идёт на вашем компьютере (whisper.cpp), поэтому программе не нужны
ни учётная запись, ни подписка, ни интернет после первой загрузки модели, а
сказанное никуда не отправляется.

## Как пользоваться

| Действие | Что происходит |
| --- | --- |
| Удерживать **правый Ctrl** | Идёт запись; отпустили — текст вставлен |
| Два быстрых нажатия | Запись без рук, до следующего нажатия |
| **Esc** во время записи | Отмена, ничего не вставляется |

Клавишу можно сменить в настройках: правый Alt, Ctrl+Win, Caps Lock, F8, F9, Pause —
или назначить свою кнопкой «Своя…»: одиночный модификатор, функциональная клавиша
или сочетание до трёх клавиш (Ctrl+Shift+D, Alt+F10). Обычная клавиша без Ctrl,
Alt или Win не принимается: она нужна для набора текста.

При первом запуске программа предложит скачать распознавание — от 150 МБ до
1,6 ГБ в зависимости от модели. Загрузка докачивается с места обрыва.

## Что умеет

- **Диктовка на любом языке**, который знает Whisper; язык фразы определяется сам
  или задаётся в настройках — для коротких фраз это точнее.
- **Печать по ходу речи** — текст появляется в активном окне, пока вы ещё
  говорите (с видеокартой NVIDIA). Печатается только то начало фразы, которое
  совпало в двух черновых расшифровках подряд; если окончательная расшифровка
  разошлась с напечатанным, расхождение стирается и набирается заново.
  Esc во время записи убирает напечатанное.
- **Проверка микрофона** — пять секунд записи, громкость и что расслышано: так
  видно, с какого микрофона распознавание точнее.
- **Словарь** — имена и термины, которые нужно расслышать верно, и замены
  «сказал так → написать так».
- **Команды голосом** — «новая строка», «новый абзац».
- **Правка нейросетью** (необязательно) — убирает слова-паразиты и оговорки,
  расставляет абзацы и списки, подбирает тон под программу: в мессенджере
  разговорный, в почте деловой, в редакторе кода — с названиями латиницей.
  Работает через Ollama на этом же компьютере или через любой сервис с
  интерфейсом OpenAI.
- **История и счётчики** — что надиктовано, сколько слов и сколько времени
  сэкономлено. Хранится только локально, отключается в настройках.
- **Память не занята зря** — модель выгружается после простоя и загружается
  снова с первым нажатием клавиши. Если рядом работает
  [Суфлёр](https://github.com/faafaafuu/asis) с той же моделью, Говор
  пользуется его сервером расшифровки, а не держит вторую копию в видеопамяти.

## Модели

| Модель | Размер | Когда |
| --- | --- | --- |
| large-v3-turbo | 1,6 ГБ | Видеокарта NVIDIA от 4 ГБ — выбирается сама |
| large-v3-turbo q5 | 574 МБ | Та же точность на процессоре, медленнее |
| small | 488 МБ | Процессор — выбирается сама, когда видеокарты нет |
| base | 148 МБ | Слабый компьютер |

## Сборка

Нужны Rust и Node.js.

```bash
npm install
```

```bash
npm run build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

Окна можно смотреть в браузере без сборки — страница подставит выдуманные данные:

```bash
node scripts/preview.mjs
```

## Проверка

```bash
cargo test --manifest-path src-tauri/Cargo.toml
```

Загрузка модели из сети с докачкой проверяется отдельным тестом:

```bash
cargo test --manifest-path src-tauri/Cargo.toml -- --ignored download
```

Печать по ходу речи — без клавиатуры и окон, на работающем сервере whisper.cpp:

```bash
GOVOR_TEST_WAV=phrase.wav GOVOR_TEST_PORT=8642 cargo test --manifest-path src-tauri/Cargo.toml -- --ignored streaming --nocapture
```

Весь путь от клавиши до вставленного текста можно пройти без микрофона: переменная
окружения `GOVOR_MIC_FILE` с путём к WAV (16 бит) подменяет запись этим файлом,
а черновики видят из него столько, сколько прошло времени от начала записи.

## Ограничения

- Только Windows 10 и 11.
- Правка нейросетью делит видеопамять с распознаванием. Если обе модели в неё не
  помещаются, правка не успевает за 20 секунд, и вставляется текст без неё —
  выберите языковую модель полегче или модель распознавания `small`.
- Текст вставляется только в то окно, в которое диктовали. Если за время
  расшифровки окно сменилось, текст остаётся в буфере обмена и в истории.
- Точность сильно зависит от микрофона: на глухой записи без верхних частот
  Whisper путает согласные, и подъём частот при обработке этого не исправляет.

## Устройство

| Файл | Что делает |
| --- | --- |
| `src-tauri/src/lib.rs` | Связка: клавиша → запись → расшифровка → правка → вставка; окна и трей |
| `hotkey.rs` | Хук клавиатуры: удержание, двойное нажатие, отмена |
| `audio.rs` | Запись с микрофона, приведение к 16 кГц |
| `whisper.rs` | Загрузка и запуск whisper.cpp, расшифровка, выгрузка по простою |
| `text.rs` | Словарь, команды голосом, чистка — без нейросети |
| `polish.rs` | Правка текста языковой моделью |
| `inject.rs` | Вставка в активное окно через буфер обмена или набором |
| `history.rs` | История и счётчики |
| `src/` | Главное окно и индикатор записи — HTML, CSS, JS без сборщика |

Данные лежат в `%APPDATA%\app.govor.dictation`, журнал — в
`%LOCALAPPDATA%\app.govor.dictation\logs\govor.log`.
